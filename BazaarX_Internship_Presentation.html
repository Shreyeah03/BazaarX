Slide 03

Project Overview – BazaarX

  • Frontend store for sneakers, streetwear, watches, headphones, and gadgets
  • Dark modern glass UI with purple and orange accents
  • Focus on reusable components, responsive layout, and smooth interactions
  • Product catalog from JSON data with INR pricing
  • Cart and wishlist saved in browser using localStorage
  • Prepared for GitHub hosting and cloud deploy (Vercel / Netlify)

Slide 04

Objectives

  • Develop homepage, shop, and product detail experiences
  • Implement search, filtering, sorting, and pagination
  • Build cart and wishlist with quantity control and persistence
  • Apply modern UX: animations, toasts, skeleton loaders, theme toggle
  • Organize code into pages, components, context, and utilities
  • Make the project deployment-ready as a static SPA

Slide 05

Technology Stack

Core

  • React.js 18
  • Vite
  • Tailwind CSS
  • React Router DOM

Supporting tools

  • Framer Motion (animation)
  • Lucide React (icons)
  • Context API + localStorage
  • Fraunces + Plus Jakarta Sans

Slide 06

System Architecture

  • Pages: Home, Shop, Product Detail, Wishlist, Checkout (placeholder)
  • UI components: Navbar, Footer, ProductCard, CartDrawer, Toast, Skeleton
  • State: CartContext, WishlistContext, ToastContext
  • Data: products.json + helpers for price, filters, and images
  • Routing: AppRoutes with React Router
  • Persistence: bazaarx-cart and bazaarx-wishlist in localStorage
  • Frontend-only architecture suitable for static hosting

Slide 07

Modules and Features

Shopping experience

  • Landing sections (hero, trending, categories)
  • Shop filters: category, price, rating
  • Product gallery with zoom-on-hover
  • Reviews and related products

User tools

  • Animated cart drawer + subtotal
  • Wishlist save / move to cart
  • Dark / light theme toggle
  • 18 products across 6 categories

Slide 08

Implementation Highlights

  • Shared state with Context API for cart, wishlist, and notifications
  • Multi-filter shop listing with 8 products per page
  • ProductImage fallback for broken remote images
  • INR formatting using Intl.NumberFormat (en-IN)
  • Responsive layout for mobile, tablet, and desktop
  • vercel.json and netlify.toml added for SPA routing after deploy
  • UI copy refined for a clean, professional product feel

Slide 09

Learning Outcomes

  • Hands-on practice with React components and Vite workflow
  • Client-side state management using Context API
  • Routing, filtering, sorting, and pagination in a real UI
  • Tailwind CSS and motion-based interface polish
  • localStorage for cart/wishlist without a backend
  • GitHub project structure and static deployment basics
  • Maintainable folder structure for frontend projects
